# 👋 Hand Gesture Recognition Using CNN

A Deep Learning and Computer Vision project developed as part of the **SkillCraft Technology Internship (Task 4)**. This application uses a Convolutional Neural Network (CNN) to accurately identify and classify 10 different hand gestures, enabling intuitive human-computer interaction.

## 🔍 Key Highlights
* **Dataset utilized:** LeapGestureRecog containing approximately 20,000 images.
* **Data Preprocessing:** Converted images to grayscale and resized to 128 × 128 pixels.
* **Model Architecture:** Built and trained a custom CNN-based image classification model.
* **Performance:** Classified 10 distinct hand gestures and achieved 99.98% test accuracy.
* **Deployment:** Integrated the trained model with a Streamlit web application for real-time image-based prediction.

## 🛠️ Technologies Used
* **Languages & Libraries:** Python, TensorFlow, Keras, NumPy, Pillow
* **Web Framework:** Streamlit
* **Version Control:** Git & GitHub
